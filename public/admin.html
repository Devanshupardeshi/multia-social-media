Which token

                
A Facebook user or System User token with ads_read. Instagram-login tokens (starting "IG") can't read ads. A System User token from Business Manager doesn't expire.

              

              

                
Who sees it

                
Any client login assigned to this Instagram account gets an Ads page for this ad account — and only this one.
